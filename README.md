# About
www.aimmxi.xyz is my personal website and a repository for all my past projects and creative works. It also serves as my own space on the internet.

The aim of this project is to offer a platform that helps me preserve the things I deem important completely free of restrictions, and perhaps even make the modern web slightly less boring.

This project uses the Hugo static website generator to simplify management and is written in pure HTML and CSS, with a few lines of JavaScript to enhance appearance and add reactiveness. The code and content present in this repository are released under the GPLv3 and CC BY-SA licenses respectively.
